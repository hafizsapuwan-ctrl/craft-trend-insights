# craft-trend-insights
A personal, read-only market-research tool for an independent digital artist. It analyzes publicly available marketplace listing data (titles, tags, price ranges) to understand current craft &amp; design trends. Insights inform original artwork that I create myself
- Read-only public endpoints only
- No user accounts, personal data, or shop access
- Respects rate limits and attribution requirements
